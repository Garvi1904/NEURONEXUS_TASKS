# NEURONEXUS_TASKS_DATA_SCIENCE

# TASK - 1:
# 🚢 Titanic Survival Prediction using XGBOOST
The aim of this project is to predict the survival of passengers on the Titanic using **XGBOOST CLASSIFIER**. We analyze the Titanic dataset to identify which features influence survival and build a predictive model based on these features.

# TASK - 2:
# 💳 Credit Card Fraud Detection using Logistic Regression

This project focuses on building a machine learning model to detect fraudulent credit card transactions using **LOGISTIC REGRESSION**. The dataset is highly imbalanced, so special care is taken during preprocessing to ensure accurate results.
Prediction is showed whether the transaction is fraudulent or genuine.
